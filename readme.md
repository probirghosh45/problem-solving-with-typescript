# TypeScript Problem Solving & OOP

This repository contains my solutions for Assignment 1, focusing on fundamental and intermediate TypeScript concepts, including type safety, generics, interfaces, and Object-Oriented Programming (OOP).

## 📚 Assignment Overview

All 8 coding problems are implemented in a single TypeScript file named `solutions.ts`, as required by the assignment instructions.

## 🎯 Learning Objectives

- Understand TypeScript types and type annotations.
- Practice optional and default parameters.
- Apply Union Types and Type Narrowing.
- Work with Tuples and Readonly Modifiers.
- Understand Generics and Generic Constraints.
- Use Interfaces and Array Methods.
- Implement Classes, Inheritance, and Access Modifiers.
- Handle asynchronous operations using Promises and Async/Await.

## 📝 Problem List & Concepts

| No. | Function / Class | Concepts |
|:---:|---|---|
| 1 | `multiplyValue` | Default Parameters |
| 2 | `processInput` | Union Types, Type Narrowing |
| 3 | `formatCoordinate` | Readonly Tuples, Destructuring |
| 4 | `concatenateArrays` | Generics, Rest Parameters |
| 5 | `getPopularCourses` | Interfaces, Array Filtering |
| 6 | `pluckValues` | Generics, `keyof`, Indexed Access Types |
| 7 | `Employee` & `Manager` | OOP, Inheritance, Access Modifiers |
| 8 | `validateAgeAsync` | Promise, Async/Await, Error Handling |

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/probirghosh45/problem-solving-with-typescript
```

**2. Navigate to the project directory**

```bash
cd problem-solving-with-typescript
```

**3. Install dependencies**

```bash
npm install
```

**4. Run the TypeScript solutions**

```bash
npx ts-node solutions.ts
```

Note: The assignment requires the final `solutions.ts` file to contain function and class implementations only, without sample test calls or `console.log()` statements.
